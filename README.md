# 🛒 Supermarket Billing System

> A simple console-based supermarket inventory and billing system developed using C++.

## 📌 Overview

Supermarket Billing System is a C++ based application designed to manage supermarket products and generate customer bills.

The system provides basic inventory management and billing functionalities through a simple menu-driven interface. It demonstrates fundamental C++ programming concepts, file handling, functions, arrays, loops, conditional statements, and basic data management.

## ✨ Features

- 🛍️ Add new products
- 📦 Display available products
- 🧾 Generate customer bills
- ✏️ Update product information
- 🗑️ Delete products
- 💰 Calculate total bill amount
- 📊 Manage product quantities
- 💾 Store product information using files
- 📝 Maintain billing and activity logs
- 🔐 Simple login interface

## 🧰 Technologies Used

- C++
- File Handling
- Functions
- Arrays
- Structures

- Loops
